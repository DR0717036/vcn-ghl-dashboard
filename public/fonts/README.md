# Fonts

Manrope (static weights 500 and 700) from Google Fonts, used by the weekly report's
server-rendered trend charts (src/lib/weeklyReport/charts.ts), where the image renderer
needs the font file itself. Licensed under the SIL Open Font License 1.1
(https://openfontlicense.org). The email's text uses Manrope through a Google Fonts
link instead; these files are not referenced by any page.
